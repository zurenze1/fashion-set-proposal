定位与需求

先想清楚：布景要替 IP 完成什么任务

服务谁
有自有服装品牌的女性时尚 IP
拍什么
以口播为主：品牌和人物故事、娱乐八卦、前沿时尚新闻；每期穿自家品牌衣服出镜，讲到穿搭时再切全身
想要的人设
懂行、有审美积累的“时尚主理人”，像在自己的工作室里和朋友聊天
谁在这里工作
IP、IP 助理（剪辑、监看、准备）、一名生活助理；每天在这里连续拍摄

目标一 · 建立信任

观众要觉得“她懂行，说的话可信”。所以背景要有内容感和品位感，不能是空白墙，也不要网红灯牌。

→ 书架、黑金画、画廊式配色

目标二 · 让衣服被看见

她卖的是衣服，版型、裤型、鞋子都得完整露出来，而且衣服要是画面里最显眼的东西。

→ 去掉桌子、全身镜头、深色背景衬浅色衣服、衣架当品牌货架
对标博主

看八个参考怎么拍：借鉴什么、怎么改、为什么

参考分三类：时尚口播和穿搭博主（怎么拍人和衣服）、有时尚感的家（怎么搭软装和配色）、奢侈品店（怎么做出贵气）。不管看哪一类，最后都只问一个问题：对口播画面有什么用。我逐条看了画面；只有配音、没有出镜的视频不算（例如 Coco抠搜选包指南）。

看完八个参考，落到口播画面上的四件事

  1. 同一个景，拍三类内容。品牌和人物故事多是横屏长视频（B 站、视频号），娱乐八卦和时尚新闻多是竖屏短视频（抖音、小红书）。景不换，只换景别：讲故事用中景，聊八卦和新闻切到胸口以上的近景，更像面对面聊天。
  2. 开灯就能拍。八卦和新闻讲究快，可能一天录好几条。主光、辅光、机位都固定，地上贴好定位标，IP 坐下、开灯、按录制，不用每次重新布置。
  3. 给字幕和配图留位置。竖屏里人放在中下部，头顶上方留出标题区；背景统一暗，剪辑叠新闻截图、明星图、小窗时都清楚（AHALOLO 一半时间都在插图）。
  4. 背景只负责“可信＋品位”。书柜和画说明她懂行，衣架说明她做品牌；不放灯牌和花哨摆件，因为八卦和新闻的配图本身已经够热闹了。

一、时尚口播与穿搭：怎么拍人和衣服

AHALOLO · 时尚评论口播

B 站约 149 万粉丝 · 视频链接

看到的：两人并排坐，胸口以上中景，镜头和眼睛同高；背景是浅灰紫墙加一道线条框，墙上不挂东西；差不多一半时间画面切到秀场图和明星图。

借鉴什么
口播要能和品牌图片来回切：背景简洁、颜色统一；人物中景、平视。
我们怎么改
背景只用一面炭黑墙，人头正后方是画，两侧对称放书柜和衣架；口播机位高约 1.2 m，和坐姿眼睛平齐。
目的
IP 讲品牌和人物时会插很多图片、秀场视频，背景越统一，剪辑越顺。
为什么不照搬
她们穿红、蓝这类饱和色，浅墙衬得住；我们的 IP 卖驼色、米白、黑这类中性色，在浅墙前会糊成一片，所以反过来用深墙衬浅衣。

当下频道 THIS · 穿搭博主人物采访

B 站 · 视频链接

看到的：采访段落里，人坐正中，胸口以上中景；背后是一排挂满衣服的衣架，压得很暗，只透出轮廓；画面里有几根竖直的灯管做线条；人脸是全画面最亮的地方。

借鉴什么
“衣服做背景、背景压暗、人最亮”：衣架本身就是时尚身份的证据，不需要别的装饰。
我们怎么改
金色衣架挂 IP 自己品牌的衣服，放在人的右后方；衣架不打正面光，只靠旁边壁灯的余光透出颜色和轮廓。
目的
观众一眼知道“她是做衣服的”，品牌一直在画面里，又不像硬广。
为什么不照搬
画面里露出灯管是纪录片的风格化做法，要多买灯、多走线；我们 3000 元预算里不做，用壁灯和灯带代替“光的线条”。

Monobin.J · 韩国穿搭试穿评测

B 站 · 视频链接

看到的：固定横屏全身机位；左边一棵大叶绿植，右边一个挂着本期衣服的衣架，背后白布垂幔；讲到哪件就从衣架上取下来换上；偶尔切到脸部近景展示耳饰；光来自左侧百叶窗。

借鉴什么
本期要讲的衣服就挂在画面里，讲到哪件取哪件；植物和衣架一左一右做出前后层次。
我们怎么改
衣架就在 IP 右后方，伸手可取；橄榄树放在右角，和左侧书柜平衡；首饰、面料靠 Pocket 3 手持补近景。
目的
画面本身就在“展示货”，观众看得到下一件是什么，愿意看下去。
为什么不照搬
她背后沙发上堆满衣服和包，显得乱；窗光一天里会变色。我们衣架只挂当期 6–8 件，其余收进镜头外的待拍衣架，并且全用人造光。

Riddlenana · 竖屏全身穿搭

B 站约 16 万粉丝 · 视频链接

看到的：每套衣服一个竖屏全身镜头，头顶留一点空，脚下露出地面；镜头大约在腰部高度；背景是一整面米白落地帘；画面角上打品牌名，穿插面料特写。

借鉴什么
穿搭单独一个竖屏全身机位，头顶到鞋完整；镜头放低，腿不显短；品牌名用字幕，配面料特写。
我们怎么改
穿搭机位放中轴约 2.8 m、高约 1.1 m；拍完全身后，IP 助理手持 Pocket 3 补一组面料和细节特写。
目的
服装品牌最要紧的是版型、长度、面料被看清。
为什么不照搬
她只讲穿搭，背景一面帘子就够；我们的 IP 还要讲品牌和人物，需要书柜和画撑起“懂行”的人设，所以全身画面里保留黑金背景。

黎贝卡 Becky · 单品讲解

时尚博主，做过自有品牌，和我们服务的 IP 最接近 · 视频链接

看到的：一张正红色皮沙发是画面主角，墙是深绿色；她坐着讲，讲到哪只包就拿起来举到胸前；包摆满沙发和地毯；固定全景。

借鉴什么
一件颜色鲜明的主椅做记忆点；讲单品时拿在手里举到胸前。
我们怎么改
焦糖丝绒圆背椅固定放在画面正中；左手边的边几上只放一件“本期单品”，讲到时顺手拿起来。
目的
每期衣服都在换，但椅子和画不变，观众刷到就认得是她。
为什么不照搬
包摆满一地，画面杂、人在全景里很小；我们用中景，一次只摆一件单品，让衣服当主角。

二、有时尚感的家：怎么搭软装和配色

最美中国家 · 一位时尚博主的家

B 站家居账号 · 视频链接

看到的：暖灰墙、深咖啡色木柜、米白布艺；客厅里一张橘色沙发上方挂三幅抽象画；斑马纹抱枕、床品做一处图案点缀；灯光都是低处的暖色光斑，没有大白光。

借鉴什么
“大面积中性色＋一件饱和色家具＋一组抽象画＋一处图案”，这是时尚人家里高级感的配方；暖光只在局部打亮。
我们怎么改
炭黑墙、黑书柜做大面积中性色；焦糖丝绒椅是唯一的饱和色；一幅黑米金抽象画在头后；地毯的黑白格边就是那一处图案；背景只用灯带和壁灯的暖光点。
目的
让镜头里的空间看起来像“一个有品位的人自己的家”，而不是摄影棚。
为什么不照搬
家居视频拍的是房间，常用广角、靠窗光，人不是主角；我们只学软装搭配和配色，机位和光还是按口播来定。

三、奢侈品店：怎么用平价东西做出贵气

Jessica 沙掌柜 · 奢侈品店主口播

B 站奢侈品账号，该视频约 81 万播放；视频标注“含虚构演绎”，背景是精品店场景 · 视频链接

看到的：竖屏、腰部以上；她穿黑色西装配金扣；背后是暖木色陈列柜，每一格单独有灯，一格只放一两件，留白很多；顶上是一排排小射灯。

借鉴什么
奢侈品店的高级感来自“少放、每格有灯、留白、对称”，以及黑配金的细节。
我们怎么改
书柜开放格每层一条暖光灯条，每层只放 2–3 样（一组书、一只包、一瓶香水，都用 IP 自己的），不塞满；画两侧的壁灯对称；IP 首饰选金色，呼应衣架和壁灯。
目的
用平价东西做出“精品店陈列”的感觉，这是 3000 元做出贵气的关键。
为什么不照搬
精品店的柜子是定制木作加整排射灯，远超预算；我们用成品黑书柜加自粘灯带做出同样的“格格有光”。

中古奢侈品店 · 坐着聊单品

B 站约 2.5 万播放 · 视频链接

看到的：两人坐在墨绿丝绒沙发上聊天，身后是一整面金色拱形陈列墙，包按颜色一格一格排开，每格有灯；讲到哪只包就拿起来细看，再切近景。

借鉴什么
“坐在发光的陈列墙前聊单品”，丝绒沙发和金色陈列架一出现就是奢侈品的语言。
我们怎么改
丝绒椅＋金色衣架＋发光书柜，同样是丝绒、金属加暖光的组合；当期单品放在书柜灯带下，讲到时拿起来，切 Pocket 3 近景。
目的
让观众把 IP 的品牌和“高级”联想在一起，讲的单品也显得贵。
为什么不照搬
整面墙摆满包、颜色很多，适合店铺；我们画面里只留一只包，颜色控制在黑、驼、米、金之内，人和衣服才是主角。
设计逻辑

六个关键决定

每一个都按“问题 → 做法 → 好处”来讲。所有东西都对应上面两个目标，不是好看就放。

1

去掉桌子，改成一把单人休闲椅

问题
常见口播坐在桌子后面，腰以下全被挡住，服装博主最重要的版型、裤型、鞋子恰好在被挡住的部分。
做法
画面中心只放一把焦糖色丝绒圆背单椅和一个小边几。口播用中景：脸和上半身的衣服看得清，手里拿着讲的单品也能入画；讲穿搭时起身站到椅旁，切到全身机位。
好处
口播和穿搭两类素材在同一个角落完成；坐着聊天比坐在桌后念稿更像真实分享。不用深沙发：人会陷进去，腰线看不清，衣服会压皱。

单椅＋左手边几＋环边圆地毯，坐着讲、站起来展示都在一个机位

2

只改一面背景墙：贴炭黑哑光墙纸，不刷漆

问题
白墙配浅色衣服，人和墙融在一起，画面没有焦点，也没有调性。
做法
镜头正后方这一面墙贴可移除的炭黑哑光自粘墙纸（约 5 m × 2.7 m），底部保留原来的白色踢脚线；黑金画挂在人头正后上方，两侧各一盏金色筒形壁灯。画面以黑、炭灰、米白、金为主，焦糖色单椅是唯一的重色，衣服里的酒红和橄榄树做少量点缀。
好处
深色背景让人脸和浅色衣服自然成为画面最亮的地方；黑金是奢侈品店和画廊的视觉语言。不刷漆是因为：房子不一定能动墙面，刷漆要两三天晾干、有气味，以后也难恢复；墙纸一天贴完，撕下来墙还是白的。哑光面不反灯光，墙纸本身的细微纹理在镜头里就是质感，所以不再加线条框。

口播横屏画面：背景墙贴炭黑哑光墙纸，画和壁灯在人头后方

3

右侧金色衣架，就是品牌货架

问题
口播背景一成不变，观众会看腻；硬广植入又会破坏真实分享的感觉。
做法
挂 6–8 件 IP 自家品牌的衣服，按 米白 → 驼 → 黑 → 酒红 排列。
好处
每期换衣服，背景就自然更新，不用花钱换布景；品牌一直在画面里，但看起来像“她工作室里的衣服”，不像广告；讲到哪件可以直接起身取下来展示。

右墙：待拍衣服按顺序挂好，旁边挂烫机、鞋架

4

左侧黑色书柜，放“懂行”的证据

问题
“懂行、有积累”不能只靠嘴说。
做法
黑色铁艺书柜，上层开放格、下层带门。开放格每层只放 2–3 样：IP 自己的书（米白和黑色书脊朝外）、香水、一只自家品牌的包；每层加暖光灯条。下柜门里收杂物，镜头里看不到。
好处
书是阅读量和审美积累最直观的视觉证据；灯条在深色墙上打出一层层暖光点，画面有了前后层次。每层少放、格格有光，是奢侈品店陈列的做法（参照 Jessica 沙掌柜）。书、香水、包都用 IP 自己的，不另买；包是自家品牌的，还多一处品牌露出。

左侧黑色书柜：下柜门收杂物，上层开放格配暖光灯带

5

只用人工光：遮光帘＋主光＋辅光＋背景暖光

问题
自然光随时间和天气变化，上午、下午、阴天拍出来颜色不一样，同一期视频剪在一起会跳色。
做法
窗户装深灰遮光帘，拍摄时全部拉上。主光按老师标准选型（≥100W、显色≥95、色温含 5600K），加柔光箱；辅光补阴影；书架灯带和壁灯负责背景暖光。
好处
每一期光线和颜色都一样，这是能持续拍下去的前提；深灰遮光帘和背景墙同色系，画面更沉稳。

遮光帘拉上，只用人工光

6

镜头外留给三个人干活：工位、换衣角、熨烫区

问题
每天要在这里连续拍：换衣服、熨衣服、补妆、剪辑、拆快递。没有地方，这些事就会堆进画面里。
做法
镜头只看得到房间中间一条，两侧墙边离背景墙 1.5 m 以后都在画外：左墙放梳妆台、换衣屏风、衣柜，右墙放落地镜、挂烫机、待拍衣架，入口墙放鞋架、收纳柜和剪辑台。
好处
动线是 衣柜 → 换衣 → 化妆 → 上镜 一条线；IP 助理坐在剪辑台后面朝拍摄区，抬头就能看到 IP；从门口到拍摄区留 1 m 通道，人走动不碰灯架。这部分预算另算。

参考依据

背景怎么做才不显廉价

我查了视频布景的公开资料，几条原则在不同来源里反复出现，方案的背景设计按这些原则来。

  1. 人离墙要有距离，背景才有纵深。人和墙之间留出几步，背景自然略虚，人更突出。本方案：人离背景墙 1.5–1.8 m。
    Subscribr：YouTube 背景技巧 · Primal Video：工作室背景
  2. 背景要单独打光。给背景单独的灯，人才不会和背景融在一起。本方案：书架灯带＋壁灯。
    Subscribr：不显廉价的背景
  3. 背景要有质感和层次，但不能杂乱。哑光表面防反光，书架、植物、灯带做层次，道具少而精。本方案：哑光炭黑墙纸、灯带书柜、橄榄树。
    Subscribr：不显廉价的背景 · Uppbeat：创作者布景 6 条建议
  4. 服装类内容用中性背景衬托衣服。背景色调中性，衣服才是主角。本方案：黑、炭灰、米白、金。
    Erase.bg：时尚拍摄背景选择
  5. 衣橱和穿搭本身就是时尚内容的看点。衣橱参观是 YouTube 时尚频道的固定内容类型，所以把品牌衣架放进背景。
    YouTube 官方博客 · Adobe：时尚视频选题
设计主张

我为什么这样设计

这套方案背后是六个判断。道具可以换，这六条不变。

一、我先想清楚这个空间替谁赚钱

她靠口播建立信任，再卖自己的衣服。所以第一优先级是口播：脸和表情看得清、声音听得清、背景一看就“懂行”；第二是让衣服被看见：我去掉了桌子，加了全身机位，把衣架做成背景里的品牌货架。好看排在后面，服务她的内容和生意排在前面。

二、我只在镜头看得见的地方花钱

镜头只拍得到房间中间一条。3000 元我全部压在这一条里：背景墙纸、镜头区地板贴、单椅和地毯、画和壁灯、主光。镜头外的工作区按实际需要逐步添置，单独算账。

三、我把光放在第一位

持续更新靠的是每一期画面都一样。所以我用遮光帘屏蔽自然光，主光按 120W、显色 95 以上的标准选。预算再紧，主光和遮光帘也不砍。

四、我设计的是每天都能开工的工作室，不是一张好看的图

这里每天有三个人在干活。我把动线排成 衣柜 → 换衣 → 化妆 → 上镜 一条线，把剪辑工位放在相机后面，让 IP 助理能一边剪一边监看。开工不用重新搭，收工不用收拾半天。

五、我用“人亮、背景暗”来控制视线

炭黑背景墙加点状暖光，让人脸和浅色衣服成为画面里最亮的地方。观众的视线会自然落在她和衣服上，背景只负责提供品位和信息。

六、我提前想好了落地时会遇到的问题

深色墙让画面偏暗，所以主光功率留足了余量；镜子放在画外、画选哑光帆布，避免反光；壁灯 3000K 和主光色温不同，主光调到 4500–5000K；墙面不刷漆，用可移除的自粘墙纸，搬走时撕掉；贴之前先在墙角小块试贴 24 小时，确认撕下不掉白灰。
